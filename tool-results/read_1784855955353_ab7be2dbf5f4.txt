     1→# BRANIFY — Project Worklog
     2→
     3→Domain: branify.store
     4→Stack: Next.js 16, React 19, TypeScript, Tailwind CSS 4, Framer Motion, shadcn/ui, Zustand
     5→
     6→## Architecture Decision
     7→Because the sandbox only exposes a single user-visible route (`/`), BRANIFY is built as a
     8→premium **single-route SPA** with a lightweight client-side router (Zustand store in
     9→`src/lib/router.ts`). The Navbar switches "views" (Home, Services, Products, Portfolio,
    10→Pricing, Blog, About, Contact, legal pages, FAQ, search, 404) by updating the store, and
    11→`src/app/page.tsx` renders the matching view component. Detail pages (product / blog / tool)
    12→are driven by a `slug` param in the same store.
    13→
    14→## Design System
    15→- Dark theme forced (`html.dark`). Colors: bg `#0B1120`, surface `#131C31`, primary `#14B8A6`,
    16→  hover `#0D9488`, text white, muted `#CBD5E1`.
    17→- Fonts: Poppins (display) + Inter (body), loaded via `next/font/google` in `layout.tsx`.
    18→- Custom utilities in `globals.css`: `.glass`, `.text-gradient`, `.shadow-glow`, `.bg-grid`,
    19→  `.animate-marquee`, `.animate-float`, etc.
